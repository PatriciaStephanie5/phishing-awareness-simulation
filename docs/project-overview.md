# Project Overview

This repository records a Mastercard cybersecurity job simulation completed through Forage. The exercise focuses on phishing awareness, safe hyperlink handling and communicating security guidance to employees.

## Objectives
1. Understand phishing as a social-engineering threat.
2. Review the simulation's reported outcomes.
3. Identify where additional awareness support may be useful.
4. Develop employee-facing guidance.
5. Recommend complementary technical and organisational controls.

This is a simulated training exercise. It does not establish that real Mastercard employees were tested or that a real corporate environment was accessed.
